# FinLedger
FinLedger is a Web3 financial infrastructure platform that enables verified businesses to tokenize invoices and trade receivables, access financing through stablecoins, and automate settlement using blockchain smart contracts.

## ⚠️ Disclaimer

FinLedger is an educational and research project.

It is not intended to provide financial, investment, legal, or regulatory
services and should not be used with real financial assets or real funds.

The smart contracts and related software have not been audited and should
not be considered production-ready financial infrastructure.
